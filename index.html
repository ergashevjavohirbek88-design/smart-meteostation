Arduino-based weather station that reads temperature & humidity and displays live data on LCD with LED indicators.

Components
🎛️
Arduino Uno
Main microcontroller that runs the program
🌡️
DHT22 Sensor
Reads temperature and humidity data
📺
LCD 16×2
Displays live temperature and humidity
💡
3× LED
Blue, Yellow, Red status indicators
⚡
3× Resistor
220Ω resistors to protect LEDs
How It Works
Temperature LED Indicator Status
Below 20°C Blue ❄️ COLD
20°C – 28°C Yellow ✅ NORMAL
Above 28°C Red 🔥 HOT
Code Snippet
// Read sensor data float temp = dht.readTemperature(); float hum = dht.readHumidity(); // Display on LCD lcd.setCursor(0, 0); lcd.print("Temp: "); lcd.print(temp); // LED logic if (temp < 20.0) { digitalWrite(LED_BLUE, HIGH); // cold } else if (temp < 28.0) { digitalWrite(LED_YELLOW, HIGH); // normal } else { digitalWrite(LED_RED, HIGH); // hot }
